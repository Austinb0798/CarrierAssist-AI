# CarrierAssist AI

CarrierAssist AI is a mock telecom customer-service platform designed to demonstrate AI engineering concepts such as API integration, agentic workflows, retrieval-augmented generation, tool calling, evaluation, and monitoring.

## Current Features

- Customer lookup
- Account status lookup
- Device and eSIM status
- Line status
- Billing lookup
- Upgrade eligibility
- Network outage lookup
- Basic troubleshooting logic
- Line restoration
- eSIM reactivation
- Health check endpoint

## Technology Stack

- Python
- FastAPI
- Uvicorn
